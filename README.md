# KentRehber

Genel işletmeler için Türkçe katalog uygulaması. Uygulama çalışma alanı `kentrehber/` klasöründedir. GitHub CI kontrolleri ve Vercel yayına hazırlığı bu depoda yönetilir.

Mevcut sürüm: Phase 2.1 genel işletme kategorileri ve görsel yönetimi. Canlı servisler (PostgreSQL, Redis, Meilisearch, Cloudflare Images) ayrıca yapılandırılmadan üretim sistemi tamamlanmış sayılmaz.
